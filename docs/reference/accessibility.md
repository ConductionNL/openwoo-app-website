# Toegankelijkheid

De OpenWoo.app **streeft** ernaar om Woo (pagina's) toegankelijk te maken voor een zo breed mogelijk publiek, ongeacht technologie of vermogen. Er daarom actief gewerkt aan het verhogen van de toegankelijkheid en bruikbaarheid van de React frontend door de community.

Deze oplossing **streeft** ernaar te voldoen aan niveau AA van de Web Content Accessibility Guidelines (WCAG 2.1). Daadwerkelijk voldoen verschilt per klant. Mochten zaken niet voldoen kan dit altijd in overleg als maatwerk aangepast worden.
